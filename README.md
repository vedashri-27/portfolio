# Vedashri Kshirsagar — Portfolio

A single-page personal portfolio (bento-dashboard style). Pure HTML/CSS, no build step.

## Files
- `index.html` — the whole site
- `assets/` — project screenshots
- `Vedashri_Kshirsagar_Resume.pdf` — linked from the Résumé button

## Host it free on GitHub Pages
1. Create a public repo named `portfolio`.
2. Upload `index.html`, the `assets` folder, and the resume PDF (keep the same names).
3. Repo → Settings → Pages → Branch: `main` / `/root` → Save.
4. After ~1 minute it's live at: https://vedashri-27.github.io/portfolio
